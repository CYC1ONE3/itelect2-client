# itelect2-client


React client for my ITELECT2 Task Manager API, made with Vite using React and JavaScript.

# GT13:
The page shows three hard-coded tasks held in `useState`, and a form that
adds a task by title without reloading the page. 
## Run it

npm install
npm run dev


Then open http://localhost:5173.
